Clipper.jl

Clipper.jl exposes Clipper2's integer-coordinate polygon clipping and offsetting API through a C-compatible library. It provides stateful clipping and offsetting engines together with convenience functions for common one-shot operations.

Geometry types

A point is represented by Point64, whose coordinates are signed 64-bit integers. A Path64 is a vector of points, and Paths64 is a vector of paths. Z-aware operations use Point64Z, Path64Z, and Paths64Z to carry an additional signed 64-bit application tag.

using Clipper

square = Point64[
    Point64(0, 0),
    Point64(10, 0),
    Point64(10, 10),
    Point64(0, 10),
]

Rect64 represents an axis-aligned rectangle. Its fields follow Clipper2's convention: top is the minimum y-coordinate and bottom is the maximum y-coordinate.

Boolean operations

Clipper64 stores subject and clip geometry across calls. Add paths, execute an operation with an explicit ClipType and FillRule, and call clear! before reusing the engine for unrelated geometry.

other = Point64[
    Point64(5, 5),
    Point64(15, 5),
    Point64(15, 15),
    Point64(5, 15),
]

clipper = Clipper64()
add_subject!(clipper, square)
add_clip!(clipper, other)
closed, open = execute(clipper, ClipTypeUnion, FillRuleNonZero)

execute returns separate closed and open Paths64 collections. Open subject paths can be added with add_open_subject!, or with add_subject!(clipper, path; closed=false).

Use execute_polytree when nesting information is required. It returns a PolyTree64 for closed contours and a separate Paths64 collection for open results.

Z-aware operations

Pass Point64Z paths to the same add_subject!, add_clip!, and add_open_subject! functions, then call execute_polytree_z. Input vertex tags are preserved; newly invented edge-intersection vertices carry Z_INTERSECTION. The result is a PolyTree64Z plus open Paths64Z paths. Narrow Point64 and tagged Point64Z inputs may be mixed; narrow inputs receive z = 0.

Offsetting

ClipperOffset offsets closed polygons or open paths. Each path requires an explicit JoinType and EndType.

offset = ClipperOffset(; miter_limit=2.0, arc_tolerance=0.0)
add_path!(offset, square, JoinTypeMiter, EndTypePolygon)
inflated = execute(offset, 5.0)

Positive deltas inflate closed polygons and negative deltas deflate them. inflate_paths provides the equivalent one-shot operation:

inflated = inflate_paths(
    square,
    5.0,
    JoinTypeMiter,
    EndTypePolygon,
)

One-shot boolean operations

The boolean convenience functions require an explicit fill rule:

union_paths(square, other, FillRuleNonZero)
intersect_paths(square, other, FillRuleNonZero)
difference_paths(square, other, FillRuleNonZero)
xor_paths(square, other, FillRuleNonZero)

union_paths(subjects, fillrule) performs a union without separate clip paths. union_self resolves self-intersections and overlapping contours within a Paths64 collection.

Geometry utilities

The remaining free functions provide direct geometry operations:

  • area and is_positive inspect polygon orientation.
  • point_in_polygon classifies a point as :inside, :outside, or :on the boundary.
  • rect_clip clips paths independently against a rectangle.
  • trim_collinear removes intermediate collinear vertices.
  • minkowski_sum and minkowski_diff require an explicit boolean indicating whether the input path is closed.

See the Reference for the complete exported API.
